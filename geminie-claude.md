EL-06 FRONTEND RULES

Before modifying UI:
1. Read docs/UI_DESIGN_SYSTEM.md.
2. Inspect existing shared components before creating new ones.
3. Never introduce emojis or Unicode icons.
4. Never introduce gradients, glassmorphism, neon effects or AI-style decorative visuals.
5. Use black/warm-white/burnt-orange palette only.
6. Use Inter for UI and JetBrains Mono for technical values.
7. Use Lucide icons.
8. Prefer concise labels over explanatory paragraphs.
9. Use progressive disclosure for technical information.
10. Reuse design tokens.
11. Keep Studio as the central workflow experience.
12. Do not create separate visual styles for individual screens.
13. Do not modify core workflow logic during a frontend-only task unless explicitly requested.
14. Before completing a UI task, inspect desktop and mobile layouts.
15. Run the application and verify the changed flow before declaring the task complete.
